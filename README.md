# Fitness Buddy — AICTE_IBM BOB Project Submission

Welcome to the main repository for **Fitness Buddy**, an AI-powered health and fitness assistant developed as part of the IBM BOB project submission.

This repository is the **outer submission repository**. It contains the complete project directory, the project presentation, and the problem statement. The actual application source code is maintained inside the `fitness-buddy` folder as a separate directory.
